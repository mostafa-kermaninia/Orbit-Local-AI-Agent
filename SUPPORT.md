# Support

Use the right GitHub channel so reports remain actionable.

## Bug

Open an **Issue** when you can reproduce a defect in ORBIT itself.

Include:

- Windows version
- Python version
- configured Ollama model
- the command you gave ORBIT
- expected behavior
- actual behavior
- redacted logs

Do not post private Telegram messages, credentials, personal audio, or tokens.

## Course / usage question

Use **GitHub Discussions → Q&A** for:

- installation questions;
- understanding the architecture;
- course exercises;
- extending a tool;
- choosing a Whisper/Ollama configuration.

## Feature idea

Use **Discussions → Ideas** first for larger changes. Small concrete improvements can use the feature-request issue template.

## Security issue

Follow [SECURITY.md](SECURITY.md). Do not publish exploit details or secrets in a normal public issue.
