# Independent implementation note

This repository is an independent implementation written from scratch from a generic feature specification for a local voice assistant.

The implementation does **not** intentionally copy source code, prompts, UI assets, icons, documentation text, or branding from another voice-assistant codebase. Generic software ideas such as speech-to-text, local LLM inference, tool calling, browser launching, messaging, memory, and text-to-speech are implemented independently here.

Before commercial publication, choose original branding and perform your own trademark clearance for the final product/course name.
