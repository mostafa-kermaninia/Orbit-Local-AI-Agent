# Code of Conduct

## Our standard

Participation in ORBIT's repository should remain professional, technical, and constructive.

Examples of expected behavior include:

- discussing code and design decisions on their merits;
- giving reproducible bug reports;
- respecting contributors and learners with different experience levels;
- avoiding harassment, threats, personal attacks, discriminatory language, and doxxing;
- never publishing another person's credentials, private messages, recordings, or personal data.

## Scope

This applies to repository Issues, Pull Requests, Discussions, code review, and other project-managed community spaces.

## Enforcement

Maintainers may edit, hide, lock, or remove content and restrict participation when necessary to protect the project community or user privacy.

For sensitive reports, use the private security-reporting path described in [SECURITY.md](SECURITY.md).
