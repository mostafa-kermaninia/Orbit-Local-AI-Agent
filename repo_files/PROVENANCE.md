# Project Provenance

ORBIT is maintained as an independent implementation of a local voice-agent architecture for the course **«آموزش پروژه‌محور پردازش صوت و گفتار با پایتون»**.

The repository is built around common software and AI concepts, including:

- speech-to-text;
- local language-model inference;
- tool/function calling;
- desktop automation;
- web retrieval;
- local persistence and memory;
- text-to-speech;
- state management; and
- a desktop HUD.

The source tree in this repository is intended to contain ORBIT-maintained source code plus normal third-party runtime dependencies installed through package managers. It should not contain source files, prompts, UI artwork, icons, or branding copied from unrelated assistant projects without an explicit compatible license and attribution.

## Contributions

Contributors must only submit code they have the right to license to this project under the repository's MIT License.

Do not submit:

- code copied from repositories with incompatible or unknown licenses;
- proprietary source code;
- model weights that are not redistributable;
- API keys, access tokens, account session files, or personal data;
- third-party artwork/assets without clear redistribution rights.
